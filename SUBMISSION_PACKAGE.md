# IEEE Aerospace Conference Submission Package

Tag: aeroconf-2027-submission-v1

## Contents
- `src/leo_edge/` - full library
- `experiments/e00-e10` - reproducible experiments
- `results/frozen/v1/` - frozen data with manifest
- `figures/fig01-fig06.png`, `figures/infographic_summary.pdf` - publication figures
- `paper/manuscript.md` - full manuscript with real results
- `docs/` - research design, novelty audit, assumptions, requirements, architecture, V&V, decision log, public release

## Reproduce
```bash
uv sync
uv run pytest
make experiments
make figures
```

The regime map that drives the paper's headline result is `figures/fig04.png`, generated by `figures/scripts/fig04_regime_heatmap.py`.

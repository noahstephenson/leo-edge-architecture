# Data

- `imagery/tiles/` holds 30 real image tiles used by `experiments/e02_image_benchmark_tiles.py` to benchmark compression, quicklook, and ROI extraction on real imagery rather than a single synthetic test image. See `imagery/README.md` for the manifest schema and licensing notes.
- Everything else in this project's results (`results/frozen/v2/`) is generated by the experiment scripts in `experiments/`, not stored as static data here.

All imagery in this repository is public or synthetic. No real operational collection targets or classified imagery are used.
